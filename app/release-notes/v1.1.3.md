# QuMesh 1.1.3

## Why you're seeing this update

Earlier 1.1.x builds shipped a broken automatic-update path on macOS.
If you saw **"An error occurred while parsing the update feed"** or
**"The update is improperly signed and could not be validated"** when
clicking *Check for Updates*, that's why — and 1.1.3 puts it right.

## What's fixed

- *Check for Updates* on macOS now works again. The update feed parses
  cleanly and the new release verifies against the public key your
  installed copy already trusts.
- Release notes (the page you're reading) are now formatted: headings,
  paragraphs, and lists render the way they're written instead of
  collapsing into a single run-on line.

## What hasn't changed

QuMesh's behaviour is otherwise identical to 1.1.0 — the AMT,
WSMAN, SOL, IDE-R, KVM, and SSH-tunnel features are unchanged. This
is a delivery fix, not a feature release.

After installing 1.1.3, future updates should arrive through *Check
for Updates* normally.
