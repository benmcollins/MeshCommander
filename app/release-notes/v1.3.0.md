# QuMesh 1.3.0

A large release that closes out the remaining AMT write-side gaps,
finishes a top-to-bottom UI/accessibility pass on the machine-details
surface, and hardens the network/terminal/secret-storage paths.

## AMT write-side: System Defense, Watchdogs, Wake Alarms, Subscriptions

The configuration features that were read-only in 1.2.0 are now full
create / edit / delete.

- **System Defense** — author L2 (`Hdr8021Filter`) and L3/L4
  (`IPHeadersFilter`) filters, group them into a
  `SystemDefensePolicy`, and bind / unbind that policy to a network
  port. The rule list now renders as cards with live counters for
  matched packets / bytes per filter.
- **Watchdogs** — add, edit, and delete
  `AMT_AgentPresenceWatchdog` entries, including a per-watchdog
  action chain editor (event-on-expiry, reset, power-cycle, …).
- **Wake alarms** — full `IPS_AlarmClockOccurrence` CRUD: one-shot or
  recurring wake schedules with editable interval / occurrence count.
- **Event subscriptions** — WS-Eventing `Subscribe` / `Unsubscribe`
  against AMT's event manager, so external listeners can be wired up
  from inside QuMesh.

## One-Click Recovery, enterprise wireless, device cert issuance

- **One-Click Recovery** — boot a machine into WinRE, a Local PBA, or
  an HTTPS-served OCR image, with the URL / cert-pin selection UI
  built into the boot dialog.
- **Wireless (enterprise)** — create and edit **EAP-TLS** and
  **PEAP** profiles alongside the WPA2-PSK editor shipped in 1.2.0.
- **Device certificates** — issue a new device cert end-to-end
  (CSR generation → CA submission → install) from the device cert
  store screen.
- **CIRA per-trigger policy editor** — set the policy that runs on
  each individual CIRA trigger (user-initiated, alert, periodic,
  home-domain).
- **AMT Setup.bin USB-key editor** — author the USB provisioning
  blob from the same machine list, no separate Intel SCS install
  needed.

## Batch actions

Multi-select a set of machines in the main list and run an action
across the whole selection — power on / off / reset, refresh, delete.
Long-running batches surface per-machine progress and stop on first
error (configurable).

## Machine-details UI / accessibility pass

The machine-details window was rebuilt from the inside.

- Every right-pane section was extracted out of the monolithic
  `MachineDetailsWindow.qml` into its own file under
  `app/qml/MachineDetails/` (Overview, Time, Hardware, EventLog,
  AuditLog, Watchdogs, EventSubs, WakeAlarms, ActiveSessions,
  WsmanBrowser, SystemDefense, UserAccounts, PinnedCertificates,
  Network, DeviceCertStore, Wireless, Cira, Power,
  SessionLaunchers).
- Each section is behind a `Loader` driven by a predicate, so a
  freshly-opened window only spins up the panels you actually look at.
- A section-level loading indicator + section-specific empty copy
  replaces the old "blank panel" while a refresh is in flight.
- A getting-started card greets users with an empty machine list,
  pointing at *Add Computer* / *Scan* / *Import*.
- A `ResultBanner` component replaces ad-hoc error/success text
  scattered through MachineDetails and Certificates.

The accessibility pass:

- `Accessible.role` and `Accessible.name` on the computer list,
  every section row, the machine-details sidebar, and every
  text-bearing form field.
- Keyboard navigation through the sidebar, the machine list, and
  the *This PC* row, with proper focus rings.
- Dialog `contentItem` roles and form-field metadata so VoiceOver /
  Narrator / Orca announce each dialog meaningfully.
- **Enter** submits every text-entry dialog. Destructive actions
  route through a unified `ConfirmDialog` and are tinted via a
  `destructive` flag on `FlatButton` / `AccentButton`.
- Raw `pixelSize` literals across QML migrated onto the `Type` scale
  tokens; new `SectionHeader` component standardises section
  titles.

## Hardening: SSH, WSMAN, terminal, secret storage

- **SSH** — `libssh` now runs non-blocking inside `SshSession`, so
  `~SshSession` is cancellable mid-handshake. DNS resolution is
  cancellable before the connect, the host-key prompt is surfaced
  to the user instead of silently auto-trusting, the worker mutex
  was narrowed to pending-host-key state only, and the tunnel
  emits `failed` if the underlying channel closes before
  channel-open completes.
- **WSMAN** — digest `Authorization` header escapes backslash /
  quote; `QXmlStreamWriter` errors propagate out of the envelope
  builder; every refresh entry is covered by the trust→retry resume;
  `QNetworkReply::error()` is checked before parsing the body; the
  digest parser no longer holds a dangling reference across the
  retry; `GetRecords_INPUT` parameters are emitted in
  schema-required order so AMT doesn't reject the envelope with
  `e:SchemaValidationError`.
- **Terminal** — UTF-8 sequences split across SOL chunk boundaries
  are stitched back together; non-BMP code points emit a full UTF-16
  surrogate pair; the CSI parameter accumulator is capped at 5
  digits with a resync-to-Ground on overflow, fixing a signed-int UB
  under hostile input.
- **IDER** — the SCSI read loop no longer pumps `processEvents`
  inside a tight while-loop; it's now timer-driven, so the GUI stays
  responsive under heavy media reads.
- **Protocol parsers** — wire-supplied lengths are validated against
  remaining-buffer bounds before use.
- **OpenSSL** — `fromPkcs12` drains the error queue properly so a
  later operation doesn't see a stale error.
- **Secret storage** — `SecretCodec` grew a v3 envelope keyed off
  the platform keystore (macOS Keychain, Windows DPAPI, Linux
  Secret Service / libsecret). Migration temp files and credential
  files are now `0600`.
- **Updater** — the Linux update path gained a TLS timeout and an
  `sslErrors` handler so a wedged proxy can't hang the in-app check.
- **CI** — `GITHUB_TOKEN` is pinned to `contents: read` in workflows
  that don't need write.

## Qt6 modernization

- `property var` replaced with typed QML properties across the
  dialog set.
- Leaf controllers and `KvmFramebuffer` declare themselves via
  `QML_ELEMENT` instead of imperative `qmlRegisterType` calls.
- Loader `active` is now driven from a binding expression, not
  flipped imperatively.
- `QQuickStyle` is pinned to `Basic` so the look matches across
  macOS / Windows / Linux.
- `Q_PROPERTY` `NOTIFY` couplings on `MigrationController` and
  `KvmFramebuffer` plug the last sources of stale QML bindings.
- C++ side modernised to `std::min` / `std::max` / `std::clamp`,
  `std::pair`, `char16_t`; strict equality, ordering, `QBuffer::open`
  return-value checks, `currentDateTimeUtc`.

## Tests + CI

- New tests cover `SshTunnel` shutdown under load, the WSMAN
  trust→retry resume path, and the GetRecords envelope shape.
- A QML-engine smoke test loads `Main.qml` headlessly on every CI
  run, on all three platforms (the Windows path now uses
  `windeployqt` so the smoke covers a realistic deploy).

## Upgrading

- **macOS** — `Check for Updates…` from the QuMesh menu, or grab the
  `.dmg` from the Releases page.
- **Windows** — `Check for Updates…` from the menu, or download the
  `.exe` from Releases.
- **Linux** — `sudo apt update && sudo apt upgrade qumesh` if you've
  added the repo (snippet in the v1.2.0 notes). Otherwise grab the
  `.deb` matching your distro / architecture from the Releases page;
  arm64 is supported on both Debian 13 and Ubuntu 26.04.
