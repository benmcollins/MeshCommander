# QuMesh 1.2.0

A larger release with three big themes: **Linux is now a first-class
platform**, **AMT provisioning is feature-complete on the write side**,
and a long list of UI/quality refinements.

## Linux support

QuMesh now ships on Debian 13 and Ubuntu 26.04 (amd64) alongside macOS
and Windows.

- Signed APT repository at <https://benmcollins.github.io/QuMesh/> —
  `apt update && apt upgrade qumesh` handles upgrades the way Sparkle
  and WinSparkle do on the other two platforms.
- `.deb` files attached to every Release for users who prefer to grab
  them directly.
- The in-app **Updates** button works on Linux too: it reads the same
  update feed Sparkle/WinSparkle do, shows the release notes you're
  reading now, and points you at either the Release page or a
  copyable `apt upgrade qumesh` one-liner.

Setup snippet — the suite name (`ubuntu26.04` / `debian13`) is detected from `/etc/os-release`:

```
. /etc/os-release
SUITE="${ID}${VERSION_ID}"

curl -fsSL https://benmcollins.github.io/QuMesh/apt-pub.asc | \
    sudo tee /etc/apt/keyrings/qumesh.asc > /dev/null
echo "deb [signed-by=/etc/apt/keyrings/qumesh.asc] \
    https://benmcollins.github.io/QuMesh $SUITE main" | \
    sudo tee /etc/apt/sources.list.d/qumesh.list
sudo apt update && sudo apt install qumesh
```

## AMT provisioning write side

The configuration features that previously needed Intel SCS or the
legacy MeshCommander web UI are now in QuMesh:

- **User accounts** — add, edit, and remove AMT users and their
  realms / Kerberos / digest passwords directly from the machine
  details window.
- **TLS mode editor + device certificate store** — provision the
  device cert, switch between server-auth and mutual-TLS, manage the
  trusted-roots list.
- **Wireless profiles** — create, edit, and remove WPA2-PSK and
  WPA2-Enterprise profiles. The wired side (802.1X) gets the same
  editor.
- **CIRA write side** — environment detection rules, user-initiated
  connection settings, MPS server CRUD, and HTTP proxy access points
  for AMT's outbound MPS connection.
- **Local AMT** — connect to the machine you're running on via Intel
  LMS's loopback interface (no IP / credentials prompt needed).

## RMCP local network scanner

A new **Scan** action discovers AMT-capable machines on the local
subnet via RMCP/UDP ping. Found hosts can be added to the inventory
with one click.

## UI / UX refinements

- New version chip in the title bar, opening a redesigned **About
  QuMesh** dialog (with the full Apache 2.0 license inline).
- The icon set across the app is now [Lucide](https://lucide.dev/) —
  no more emoji rendered as boxes on machines without the right font.
- Save dialogs in KVM and SOL now suggest a sensible default filename
  (`<machine>-<timestamp>.png` / `.cast` / `.mov`).
- The "via SSH" indicator now sits under the IP and names the jump
  host, instead of a generic "via SSH" tag.
- Short machine-details windows no longer cut off the sidebar — it
  scrolls now.
- KVM and SOL active sessions are surfaced in a status pane on each
  machine row, so it's clear when something's already attached.

## Under the hood

- **KVM** now defaults to zlib-RLE compression. KVM screen recordings
  are written as QuickTime `.mov` containers (was `.avi`) so any
  modern player can scrub them.
- **SSH tunnels** get a per-machine zlib-compression toggle.
- **Event log** decoder now parses `AMT_MessageLog`'s 21-byte event
  records into human-readable text.
- **SSH + WSMAN + redirection** all share a unified async tunnel
  layer — fewer race conditions when bringing up a machine, and the
  UI stays responsive under slow links.
- `wsman:` SetHighAccuracyTimeSynch now sends Ta0 / Tm1 / Tm2 in the
  order Intel's clock-sync handler expects.
- The default branch was renamed `master` → `main`.

## Upgrading

- **macOS** — `Check for Updates…` from the QuMesh menu, or grab the
  `.dmg` from the Releases page.
- **Windows** — `Check for Updates…` from the menu, or download the
  `.exe` from Releases.
- **Linux** — `sudo apt update && sudo apt upgrade qumesh` if you've
  added the repo (see instructions above). Otherwise grab the `.deb`
  matching your distro from the Releases page.
